# Environment Setup

To complete this project, you will need to have access to Microsoft 365 apps with a Microsoft 365 Copilot license. Below are detailed instructions for setting up your environment and understanding the tools required.

## Microsoft 365 Access

Ensure that Microsoft Office 365 is installed and includes a Copilot license with the appropriate level for the apps used in this project.

> Note: Standard family licenses of Office 365 typically do not include Copilot functionality.

If needed, use the online version of Microsoft 365, as all exercises can be completed successfully online.

---

# Project Environment

This project leverages your Microsoft 365 apps enhanced with Copilot to simulate real-world workflows.

Your goal is to resolve supply chain issues through structured activities that integrate the following tools:

- Word
