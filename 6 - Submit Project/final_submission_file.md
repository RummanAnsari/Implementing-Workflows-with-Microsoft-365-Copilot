# Implementing Workflows with Microsoft 365 Copilot

## Project Submission Overview

This project demonstrates the use of Microsoft 365 Copilot tools to address critical supply chain issues impacting production operations and FDA compliance within a pharmaceutical company environment.

The project focuses on workflow optimization, data analysis, cross-functional collaboration, professional reporting, and executive-level presentation development using Microsoft 365 Copilot.

---

# Project Objective

The objective of this project is to simulate real-world pharmaceutical supply chain management challenges and demonstrate how Microsoft 365 Copilot can improve:

* Workflow efficiency
* Regulatory compliance processes
* Data analysis and reporting
* Team collaboration
* Executive communication

# Library of Copilot Prompts

## Task 1 – Email Summary Prompt

### Purpose

Summarize the supply chain issue email and identify key risks and actions.

### Prompt

```text
Summarize the attached email regarding supply chain disruptions impacting FDA compliance. Identify the top three critical issues and recommend five actionable next steps.
```

---

## Task 1 – Report Generation Prompt

### Purpose

Generate a professional supply chain review document.

### Prompt

```text
Create a professionally formatted Supply Chain Issues Review document including an introduction, business problem overview, action items, and conclusion based on the summarized email findings.
```

---

## Task 2 – Meeting Invite Prompt

### Purpose

Generate a professional cross-functional meeting invite.

### Prompt

```text
Create a meeting invite titled “Supply Chain Issues Review” including stakeholders from procurement, regulatory affairs, quality assurance, and supply chain management. Include a detailed agenda.
```

## Task 2 – Action Plan Prompt

### Purpose

Generate a structured action plan from the Teams transcript.

### Prompt

```text
Based on the Teams meeting transcript regarding supply chain compliance issues, create an Action Plan including immediate actions, short-term actions, ongoing strategies, and compliance-focused recommendations.
```

```text
Analyze the Supply Chain Report.xlsx data and generate insights including average delivery timelines by risk level, delayed component performance, and supplier reliability trends.
```
